> A privacy-preserving machine learning framework designed to enable collaborative healthcare model training without centralizing sensitive patient information.

### Project Overview

Traditional machine learning often requires collecting data in one centralized location.

This project explores **Federated Learning**, where participating healthcare clients train models locally and contribute model updates to a shared global model.

### Features

✅ Decentralized model training  
✅ Federated averaging  
✅ Local model training  
✅ Secure model aggregation  
✅ Heart disease prediction  
✅ Healthcare data management  
✅ Flask-based web application  
✅ Model training and prediction visualization  

### Architecture

```text
            Healthcare Data
                  |
                  v
        Multiple Local Clients
                  |
         -------------------
         |        |        |
         v        v        v
      Client 1 Client 2 Client 3
         |        |        |
         v        v        v
       Local Model Training
         |        |        |
         -------------------
                  |
                  v
          Model Updates
                  |
                  v
       Federated Aggregation
                  |
                  v
           Global Model
                  |
                  v
       Heart Disease Prediction
```

### Key Highlights

- Developed a privacy-preserving federated learning framework.
- Implemented local model training and federated averaging.
- Achieved **92% prediction accuracy** as reported in the project resume.
- Developed a Flask application for patient data management.
- Integrated model training and prediction visualization.
- Designed a decentralized approach for handling sensitive healthcare data.
